# SpikingCrazyflie Package

This is the main package for SpikingCrazyflie, containing the core functionality for training and evaluating spiking neural networks for drone control.

## Structure

The package is organized as follows:

- `spikingcrazyflie/`: Main package directory
  - `models/`: Neural network models (to be implemented)
  - `environments/`: Environment wrappers (to be implemented)
  - `utils/`: Utility functions (to be implemented)
  - `algorithms/`: Reinforcement learning algorithms (to be implemented)

## Usage

After installation, you can import the package as follows:

```python
import spikingcrazyflie as scf
```

For more detailed usage examples, please refer to the main README.md file in the repository root.
